## Question 2

(K&R Exercise 6-4) Write a program that prints the distinct words in its input sorted into decreasing order of frequency of occurrence. Precede each word by its count and one space. List out the command(s) used to run the program as well.  

Hint: First count all the words, then use a tree, but compare counts rather than words.  

Compile Steps:  

gcc q2.c  

Command(s) to run:  

.\a.out < test1.txt  
.\a.out < test2.txt  

Output:  

For test 1:  
4 boo  
3 hi  
2 apple  
1 cooper  

For test 2:  
10 j  
9 z  
8 l  
7 g  
6 i  
5 f  
4 d  
3 c  
2 b  
1 x
